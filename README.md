
# Personal Portfolio - Accessibility and Visual Design

## Project Overview

This is my personal portfolio website, created using
HTML, CSS, and JavaScript. It includes my homepage,
projects, and About/Contact page.

I updated my website to improve its accessibility,
visual design, and responsive layout.

## Accessibility Improvements

1. I added proper page titles and language
   information to help screen reader users.

2. I used organized heading levels so visitors
   can understand and navigate the content.

3. I improved the color contrast between text
   and backgrounds to make everything easier to read.

4. I added visible focus styles to help people
   who navigate websites using a keyboard.

5. I added labels to my contact form so screen
   readers can identify each input field.

6. I used fieldset and legend elements to group
   related form questions.

7. I added error messages and aria-invalid states
   so users can identify and correct form mistakes.

8. I added a skip navigation link on my About page
   so keyboard users can reach the main content.

## Gestalt Principles

### 1. Proximity

I used proximity by keeping related information
together inside each project card. The headings
and descriptions are close to each other,
making the content easier to understand.

### 2. Similarity

I used similarity by giving my project cards
the same colors, borders, fonts, and spacing.
This creates a consistent design and makes
the website easier to follow.
