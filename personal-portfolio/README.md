# David's IT Portfolio — HTML Skeleton

A three-page personal IT portfolio built for a web development assignment. The site currently uses semantic HTML only, with no CSS.

## Pages
- `index.html` — Home and featured work
- `projects.html` — Project summaries
- `about.html` — Background, skills, and contact information
- `wireframe.png` — Layout plan for all three pages

## Planned visual design (not implemented yet)
- Colors: Navy `#0F172A`, Sage Green `#10B981`, Light Gray `#F3F4F6`, White `#FFFFFF`
- Headings: Poppins
- Body: Open Sans

## Open locally
Open `index.html` in a browser. Use the navigation links to switch pages.
